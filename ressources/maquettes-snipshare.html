Validation d'email en JavaScript

Par @philippe_lambert • Il y a 2 heures Public

Cette fonction permet de valider rapidement une adresse email en utilisant une expression régulière. Pratique pour les formulaires d'inscription ou de contact.

JavaScript Validation Regex
const validateEmail = (email) => { return /^[^\s@]+@[^\s@]+\.[^\s@]+$/.test(email); }; // Exemple d'utilisation console.log(validateEmail("user@example.com")); // true console.log(validateEmail("invalid-email")); // false
