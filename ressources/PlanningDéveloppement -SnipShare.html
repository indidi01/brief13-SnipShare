Sprint 1 - Authentification & Base

📅 27 - 28 octobre 2025 (2 jours)

5
User Stories
16h
Temps estimé
🎯 Objectif du sprint
Mettre en place les fondations du projet : authentification complète (inscription, connexion, déconnexion) et CRUD basique des snippets (création et visualisation). À la fin de ce sprint, un utilisateur doit pouvoir s'inscrire, se connecter et créer/voir un snippet.

🔨 Tâches techniques

T1.1 - Configuration initiale du projet
DevOps ⏱️ 2h
Mise en place de l'architecture et des outils de base
Initialiser projet Node.js + TypeScript (backend)
Initialiser projet React + TypeScript (frontend)
Configurer ESLint, Prettier
Créer structure MVC backend
Créer structure Atomic Design frontend
T1.2 - Configuration PostgreSQL
DevOps ⏱️ 1h
Mise en place de la base de données
Installer PostgreSQL
Créer la base de données "snipshare"
Configurer connexion avec pg/node-postgres
Exécuter le script LDD (création des tables)
T1.3 - Backend : Inscription utilisateur
Backend ⏱️ 2h
API d'inscription avec validation et sécurité
Créer modèle User (users table)
Route POST /api/auth/register
Validation : email unique, pseudo unique, mot de passe fort
Hash du mot de passe avec argon2
Génération du token JWT
US01
T1.4 - Frontend : Page d'inscription
Frontend ⏱️ 1.5h
Formulaire d'inscription avec validation
Composant RegisterForm
Validation côté client (regex, confirmation mot de passe)
Gestion des erreurs (affichage messages)
Redirection après succès
US01
T1.5 - Backend : Connexion utilisateur
Backend ⏱️ 1.5h
API de connexion avec token JWT
Route POST /api/auth/login
Vérification email + mot de passe
Génération token JWT
Cookie httpOnly sécurisé
US02
T1.6 - Frontend : Page de connexion
Frontend ⏱️ 1h
Formulaire de connexion
Composant LoginForm
Gestion des erreurs
Stockage du token
Redirection après connexion
US02
T1.7 - Backend : Déconnexion
Backend ⏱️ 0.5h
Route de déconnexion
Route POST /api/auth/logout
Suppression du cookie
US03
T1.8 - Frontend : Bouton déconnexion + Header
Frontend ⏱️ 1h
Header avec navigation et déconnexion
Composant Header
Bouton déconnexion
Gestion de l'état authentifié
Navigation conditionnelle

T1.9 - Backend : Créer un snippet
Backend ⏱️ 2h
API de création de snippet
